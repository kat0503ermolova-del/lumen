# Lumen — планер

Календарь-планер: быстрые задачи, повторы, дни рождения, категории, заметки и «когда-нибудь», цитата дня,
утренний экран «Мой день», итоги недели, праздники РФ и международные, темы «Золото», «Розовый», «Ночь» и свои цитаты.
Сборка не нужна: обычные HTML, CSS и JS.

## Запуск

```bash
python3 serve.py
```

- На компьютере: http://localhost:5173
- На iPhone/iPad (в той же Wi-Fi сети): http://<IP-адрес Mac>:5173 → «Поделиться» → «На экран Домой»

## Данные

Пока всё хранится локально в браузере (localStorage), отдельно на каждом устройстве.
Резервная копия: меню «•••» → «Сохранить резервную копию» / «Восстановить из копии».

## Структура

- `index.html` — разметка, диалоги
- `css/styles.css` — темы, стекло, адаптив
- `js/app.js` — состояние, виды День/Неделя/Месяц/Год, заметки
- `js/parse.js` — разбор ввода на русском («завтра в 10 … !! #работа», «по будням», «др Оли 15.10.1995»)
- `js/recur.js` — повторяющиеся задачи
- `js/data.js` — праздники, цитаты, поздравления
- `js/confetti.js` — конфетти
- `sw.js`, `manifest.webmanifest` — офлайн и установка как приложения
